Roles, content, and what each one converts.

Mīzān audits the self. This audits the work that leaves the building — what was applied for, what came back, what was published and what it returned. Every figure here is a claim about a real person, so none of it is stored anywhere but this browser. No network request is made by this page.

Where things stand

Counts exclude demonstration data. A number that would be a claim about you is never computed from synthetic rows.

The board

Stage is where a role actually is, not where it was left. Anything not touched in 30 days is flagged — a stalled application is a rejection that has not been written down yet.

What converts

The only honest way to read a rejection is against the base rate. Below about 20 applications these ratios are noise, and the panel says so rather than drawing a conclusion for you.

Where it ends, and why

Recorded reasons only. An unrecorded reason is left blank rather than guessed at — the point of the panel is to show you what you actually know.

Content ledger

Mirrors tools/linkedin/posted.md. Two per week, Tuesday and Thursday. Subscribers and enquiries are what this feed is for; impressions are the vanity column and are shown last on purpose.

Data

Everything lives in this browser's local storage under one key. Export writes a file to your machine. Nothing is transmitted, and there is no server to transmit to.

This page is unlinked and carries a noindex tag. That is courtesy to crawlers, not protection. The file itself is public, because every branch of this repository is public. The protection is architectural instead: no application, rejection, employer or figure you enter here is ever written to a file that git can see. If you want a record off this device, use Export and put the file somewhere private.
