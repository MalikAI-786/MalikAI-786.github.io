# Deck templates

Two reusable PowerPoint templates, generated by `build_decks.js` — the same
single-source-of-truth discipline as the rest of `assets/brand/`: nothing is
drawn by hand, everything re-cuts from the constants at the top of the script.

| Deck | Identity | Use |
| --- | --- | --- |
| `assets/brand/decks/fiu-dba-deck.pptx` | His geometry, FIU Blue `#081E3F` and Gold `#B6862C` — the same rule the FIU email signature follows | Every FIU DBA presentation: cohort, faculty, qualifying-exam, defense |
| `assets/brand/decks/audit-the-algorithm-deck.pptx` | The Reference Mark: ember, warm graphite, warm paper | The advisory practice — client and speaking decks |

Seven slides each: title · agenda · claim + evidence card · three stat tiles ·
four-step method · the record · close with links. Swap the text, keep the
structure. Fonts are metric-safe (Cambria / Calibri / Courier New), so what
you see is what PowerPoint ships.

Both decks close on a one-line colophon disclosing AI assistance —
deliberately readable, deliberately not a watermark. It stays.

## Rebuild

```sh
# 1. rasterize the marks (cairosvg, same dependency as make_profile_hero.py)
python3 - <<'EOF'
import cairosvg
for src, dest in [
    ("assets/brand/platforms/mark-fiu-dark.svg",  "/tmp/deckassets/mark-fiu-on-dark.png"),
    ("assets/brand/platforms/mark-fiu-light.svg", "/tmp/deckassets/mark-fiu-on-light.png"),
    ("assets/brand/mark-ember.svg",               "/tmp/deckassets/mark-ember-on-light.png"),
    ("assets/brand/mark-ember-dark.svg",          "/tmp/deckassets/mark-ember-on-dark.png"),
]:
    cairosvg.svg2png(url=src, write_to=dest, output_width=640, output_height=640)
EOF

# 2. build (pptxgenjs must be on NODE_PATH or installed next to the script)
node tools/decks/build_decks.js /tmp/deckassets assets/brand/decks
```

Never hand-edit the `.pptx` files themselves for template changes — change the
generator and rebuild, or the next rebuild silently destroys the edit. Filling
in a copy of the template for an actual presentation is of course the point.
