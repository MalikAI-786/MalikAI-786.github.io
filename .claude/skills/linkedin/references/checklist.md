# Pre-flight checklist

Run this against every draft before calling it finished. Record the result at
the bottom of the draft file.

## Safeguards — any failure blocks the post

- [ ] **Nothing is being transmitted.** The draft is a file. It has not been
      posted, scheduled, DM'd, or handed to a scheduling tool.
- [ ] **No invented facts.** Every date, title, employer, credential, metric,
      client and citation traces to source material. Gaps are marked
      `[UNVERIFIED: ...]` rather than filled.
- [ ] **No private material.** No client names, employer-internal detail,
      participant data (IRB-25-0462), family, legal matters, medical history,
      addresses, or his own readings from the instrument.
- [ ] **No link to `mizan/`.** The instrument is `noindex` and unlinked. Posts
      point at `instrument.html`.
- [ ] **Research not overstated.** The DBA is in progress. Nothing is
      peer-reviewed, replicated or concluded unless it says so with a citation.
- [ ] **Attributions verified.** Especially any classical saying — check
      whether it is Qur'an, ḥadīth, athar, or Iqbal, and name which.

## Register

- [ ] **Delete the citation. Does the argument still stand?** If not, rebuild.
- [ ] No claim about what God wants, requires or rewards.
- [ ] No implication the reader should adopt the practice or the faith.
- [ ] Every term glossed in plain English at first use.
- [ ] Would this survive being read aloud by someone who disagrees with it?

## Voice

- [ ] Opens on the problem or the finding. Not on the author.
- [ ] One argument, developed once.
- [ ] Concrete before abstract — a control, a document, a year, a moment.
- [ ] No hype vocabulary, no exclamation marks, no emoji, no "leverage" as a
      verb, no "Here's the thing:", no rhetorical question as a section break.
- [ ] Paragraph breaks follow the argument's joints, not a manufactured rhythm.
- [ ] No summary paragraph restating the post.
- [ ] Ends on a genuine open question.

## Mechanics

- [ ] The text before the first line break is a complete, working hook that
      stands alone, and the whole hook lands inside 200 characters.
- [ ] Body under 3,000 characters. Target 1,200–2,400. If it is over, look for
      a second argument to cut whole rather than trimming evenly.
- [ ] No argument here is already carried by the post before or after it in the
      queue. Check the neighbours, not just this file.
- [ ] One link, in the first comment, referenced in plain words in the body.
- [ ] First comment drafted in the same file.
- [ ] Three hashtags, at the end, from the steady set.
- [ ] Exactly one call to action.

## Record

- [ ] Character count noted in the file.
- [ ] Series item recorded, if it is a Measures post.
- [ ] `posted.md` row prepared, so the ledger is not reconstructed from memory
      later.
