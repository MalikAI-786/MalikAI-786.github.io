# Corpus register

Three tiers. Nothing moves up a tier without checking against a printed kulliyāt or scholarly edition. This file records checking status; it is not itself the authority.

## Tier B — provisional
Usable in discussion, not publication or merch, until source is confirmed.
- افراد کے ہاتھوں میں ہے اقوام کی تقدیر / ہر فرد ہے ملت کے مقدر کا ستارہ
- عمل سے زندگی بنتی ہے جنت بھی جہنم بھی
- محبت مجھے ان جوانوں سے ہے / ستاروں پہ جو ڈالتے ہیں کمند

## Tier C — disputed or rejected
Do not publish without new primary/scholarly evidence.
- قتلِ حسین اصل میں مرگِ یزید ہے — widely circulated as Iqbal; treat as disputed until a reliable page reference is produced.
- Generic motivational Urdu couplets tagged “Allama Iqbal” — assume unverified until sourced.

## Working rules
Virality is not provenance. Persian is not Urdu. A translation must be identified as a translation. Edition differences matter. Failed checks stay recorded in Tier C so the same error is not rediscovered later.
