# Decode record

Fill this after reading frames. Keep observation separate from interpretation.

```markdown
# <slug> — decoded <date>

## 1. Inventory — what is actually there
Duration · aspect · cuts · text-frames vs face-frames
On-screen text, verbatim, in order, with timecodes
Typography, motion, audio status, caption as posted

## 2. Reading — what the reel is doing
Beat map: hook / line / plain reading / turn / source
Argument in one sentence
Hook: what is put at risk in the first 1.5s?
Provenance shown? Y/N and is it correct?
Series: which of the five, or none

## 3. Changes — ranked
1. …
2. …
Each with the reason.

## 4. Provenance check
Couplet
Claimed source
Register tier: A / B / C
Action: safe / verify first / do not publish

## 5. Merch signal
Does the line clear the three gates?
```

Read `scene/` in order first, then `grid/`. Transcribe before interpreting. Notice absences such as no source, no hook or no reading. More than roughly 1.5 seconds before the first idea lands is usually a structural problem in this format.
