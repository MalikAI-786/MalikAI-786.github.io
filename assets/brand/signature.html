Select a block, copy it, and paste into Gmail › Settings › Signature. Gmail lets you save several and pick one per message, which is the point of having three. Copy the signature itself, not the dashed frame around it.

3 · Reply

For the second message onward, and for phones. They already know who you are; repeating the full block in a four-message thread is noise. One line, one rule, no image — so it never trips an image blocker or a data warning on mobile.

Two things that break signatures

Do not paste it as an image. A screenshot of a signature has no working links, disappears when images are blocked, and is unreadable to a screen reader. These are HTML tables on purpose.

Do not let Gmail restyle it. If the fonts come out wrong after pasting, undo, then paste again with Ctrl/Cmd + Shift + V and check the mark still appears. Gmail occasionally strips a table cell on the first attempt.
